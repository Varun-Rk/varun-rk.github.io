    Mission 03 · Agents III: Learn · LayerFive

    AI Inbox & Outcome Tracking

    The problem

    Agents that run again and again repeat themselves, forget what the team rejected, and never find out whether their advice worked.

    What I built

    A loop that lets agents learn from their own advice. The AI Inbox tracks recommendations across runs and folds repeats into one, so no task is filed twice. A daily outcome check asks whether each one worked. pgvector memory feeds the results back, so agents read past outcomes, rejections and team comments before proposing anything new.

    checks on whether each recommendation actually worked.

    Bayesian Marketing-Mix Modeling

    The problem

    Mission 05 · Data & ML: Read · LayerFive

    Multilingual Content Categorization

    The problem

    News publishers wanted to know what readers actually read. But their pages came in five languages, often mixed on the same page, at millions of visits a day.

    What I built

    A daily pipeline that detects each page’s language, mixed pages included, and hands it to a small translation model picked for that language. The text is then mapped to the IAB taxonomy with keyword matching. Every model runs locally, on CPU.

    Mission 08 · Vision: Live · Dimaag-AI

    Process Monitoring for Chemical Manufacturing

    The problem

    A chemical changes form as it’s made: liquid, solid, granules, then powder. The plant needed the exact time of each change, from three live video streams, even on poor footage.

    What I built

    After my promotion, I led a team of 4 engineers to build it. Image classification labels the phase in every frame, and a decision algorithm pins the exact moment of each switch. Three streams run in parallel, and each run ends in a phase-timing report for later analysis.

    <100ms

    end-to-end latency across three parallel streams.
